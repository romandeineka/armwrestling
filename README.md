# Журнал столу

Домашній журнал підходів для армреслінгу. Вага і повтори вписуються на сторінці, перевіряються на сервері і зберігаються в Postgres.

## Запуск

```bash
npm install
npm run dev
```

Сайт: http://localhost:3000

Перевірка правил журналу:

```bash
npm test
```

## Куди йде один підхід

1. Форма в браузері збирає ручку, руку, кілограми, повтори і дату.
2. Браузер надсилає `POST /api/sets`.
3. `src/app/api/sets/route.ts` лише приймає запит і віддає відповідь.
4. `src/server/journal.ts` перевіряє цифри і рахує рекорд.
5. `src/db/schema.ts` описує таблиці. Файл бази лежить у `data/journal` і в git не потрапляє.

Кілограми в базі зберігаються як грами: 22.5 кг це 22500. Так десяті не губляться.

## Перший коміт

У коміт входить код. Не входять `node_modules`, `.next` і `data`.

```bash
git add -A
git commit -m "Додати журнал підходів зі збереженням у базу"
```
